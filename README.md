 # IT System Health Monitor
**IT System Health Monitor** – Developed a web-based dashboard using Python, Flask, and psutil to monitor CPU, memory, disk usage, network traffic, and system information in real time. Features a clean interface with system health indicators and performance warnings.



A web-based dashboard built with Python and Flask to monitor system performance and display important system health metrics in real time.

## Features

* **CPU Monitoring:** Track CPU usage percentage.
* **Memory Monitoring:** View RAM usage and total memory.
* **Disk Monitoring:** Monitor disk usage and storage capacity.
* **Network Monitoring:** View network data sent and received.
* **System Information:** Display operating system, processor, hostname, and IP address.
* **Health Alerts:** Identify elevated resource usage.
* **Dark UI:** Clean and user-friendly dashboard.

## Technologies Used

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/IT-System-Health-Monitor.git
   ```

2. Open the project folder:

   ```bash
   cd IT-System-Health-Monitor
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python app.py
   ```

5. Open your browser and visit:

   `http://127.0.0.1:5000`
